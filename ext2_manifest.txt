# WynlandOS ext2 root filesystem manifest
#
# Transcribed 1:1 from the old FAT32 Makefile's mmd/mcopy recipe
# (Phase 20e), with exact-duplicate host->image mappings de-duplicated
# (mtools' -o silently overwrote them; debugfs write fails on an
# existing destination, so they must not appear twice).
#
# D  /dir              -- directory
# F  /dest host/src    -- required file (build fails if missing)
# Fo /dest host/src    -- optional file (skipped if host source absent)
#
# NOTE: debugfs `write` fails COMPLETELY SILENTLY if the destination's
# parent directory isn't in the D list. Every F below must have its
# parents declared; build_ext2_image.py verifies every required
# destination afterwards and fails the build loudly otherwise.
