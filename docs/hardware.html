Где работает и как собратьWhere it runs and how to build it

Разработка идёт в QEMU: он эмулирует ПК (процессор x86_64, GPU, диск, USB), и на нём автотесты загружают ОС. Ноутбук ASUS VivoBook 15 (Intel i3-1115G4) — настоящее железо: система загружается с USB-флешки и работает на его собственных деталях.Development happens in QEMU, which emulates a PC (x86_64 CPU, GPU, disk, USB). Automatic tests boot the OS there. The ASUS VivoBook 15 (Intel i3-1115G4) is real hardware: the system boots from a USB stick and runs on the laptop's own parts.

СборкаBuild

Нужна Ubuntu 26.04 (нативно или в WSL2) с KVM.You need Ubuntu 26.04 (native or WSL2) with KVM.

# toolchain, QEMU and OVMF
./setup.sh

# kernel, bootloader and the disk image
make

# boot it in QEMU with virgl 3D
make run-gl

# a USB stick image (dd, or Rufus in DD mode)
make live

Пользовательское окружение (Qt, WebKit, GStreamer, PipeWire, Python, fish, coreutils) берётся из пакетов Ubuntu и Debian и собирается скриптами tools/stage_*.sh. Части можно отключить: WITH_QT6=0, WITH_GST=0, WITH_WPE=0, WITH_BASE=0.The userland (Qt, WebKit, GStreamer, PipeWire, Python, fish, coreutils) comes from Ubuntu's and Debian's packages, staged by tools/stage_*.sh. Leave parts out with WITH_QT6=0, WITH_GST=0, WITH_WPE=0 or WITH_BASE=0.

ТестыTests

make run-gl AUTOTEST=1 — загружает тестовые программы вместо рабочего стола: жизненный цикл процессов, оболочка и утилиты, Python, Node, учётные записи, пакеты, песочница, OpenGL, KMS, звук и PipeWire, политика памяти JIT, GStreamer, страницы WebKit, включая YouTube.boots the test programs instead of the desktop: process lifecycle, the shell and tools, Python, Node, accounts, packages, sandboxing, OpenGL, KMS, sound and PipeWire, the JIT memory policy, GStreamer, WebKit pages including YouTube.
