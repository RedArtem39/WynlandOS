Что работает сейчасWhat works today

Рабочий стол, оболочки, учётные записи, браузер с видео, звук, инструменты и ядро, которое запускает программы Linux без изменений.A desktop, shells, accounts, a browser that plays video, sound, tools, and a kernel that runs Linux programs unmodified.

Рабочий столDesktop

Zerp 2.0 рисует только окна. Панели, запуск программ и уведомления рисует оболочка. Окна раскладываются плиткой или на бесконечном холсте для каждого рабочего стола (Alt+G).Zerp 2.0 draws only windows. Panels, launchers and notices are drawn by the shell. Windows tile, or sit on an infinite canvas per workspace (Alt+G).
