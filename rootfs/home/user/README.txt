Welcome to WynlandOS.

This is your home folder (/home/user). Everything here belongs to you;
the rest of the system belongs to root.

  Files      the file manager (dock, or Alt+D)
  Terminal   Alt+Enter

Becoming root:
  ary login     create the superuser (first time only)
  ary su        a root shell in the terminal ('exit' to leave)
  ary <cmd>     run one command as root
  ary passwd    change the root password
